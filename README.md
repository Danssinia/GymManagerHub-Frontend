
# GymManagerHub – Frontend

A modern web application frontend for GymManagerHub, a gym management platform built to provide a user-friendly interface for managing gym-related operations.

## 🚀 Tech Stack

- **Framework:** Next.js 16
- **Library:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4

## ✨ Overview

GymManagerHub is a gym management platform focused on providing a centralized digital experience for gym operations. This repository contains the frontend application, built with Next.js and React.

## 📦 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone YOUR_FRONTEND_REPOSITORY_URL
```

Navigate into the project directory:

```bash
cd GymManagerHub-Frontend
```

Install dependencies:

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Builds the application for production |
| `npm run start` | Starts the production server |
| `npm run lint` | Runs ESLint |

## 🏗️ Production Build

```bash
npm run build
npm run start
```
